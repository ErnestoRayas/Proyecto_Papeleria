# Prototipo académico

Aquí se conserva el frontend original como referencia histórica del proyecto universitario. No forma parte del bundle ni de la aplicación actual, cuyo punto de entrada es `src/main.jsx`.

El prototipo utilizaba cuentas, contraseñas, inventario y ventas en `localStorage`. La versión actual usa una API y SQLite para las cuentas, sesiones, productos y pedidos. Las dependencias antiguas de Create React App y las bibliotecas de animación se retiraron del proyecto activo.
