# Imágenes del catálogo

Copias locales de las imágenes enlazadas en el proyecto académico original, optimizadas a WebP con un máximo de 600 × 600 píxeles. Se sirven desde `/products/` para que el catálogo no dependa de peticiones a un proveedor de imágenes externo.

Las direcciones originales se conservan en `shared/data/products.json` como `sourceImage`.
